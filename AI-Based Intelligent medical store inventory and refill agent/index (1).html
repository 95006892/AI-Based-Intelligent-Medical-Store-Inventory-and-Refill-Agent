Where each concept is used

Intelligent agent
Perceives stock and sales, decides what to reorder, acts by drafting orders.
Problem solving
Delivery is formulated as states, actions, goal test and path cost.
BFS
Uninformed search: fewest steps, but explores almost every cell.
A* search
f(n) = g(n) + h(n) with Manhattan distance: same optimal path, fewer cells explored.
CSP
Supplier choice as variables, domains and constraints.
Backtracking
Undo the last assignment when a constraint breaks, then try the next supplier.
